# AS2 - System Administration Project

## Overview
This project demonstrates basic Linux system administration and Git version control on the school lab server.

## System Information Script
The `scripts/sysinfo.sh` script generates a system information report containing:
- Hostname
- Current date and time
- Operating system
- Linux kernel version
- Memory usage
- Disk space

## Requirements
- Linux environment
- Bash shell
- Standard Linux utilities: hostname, date, uname, free, and df

## How to Run
From the project directory, run `./scripts/sysinfo.sh`.

If needed, make the script executable with `chmod +x scripts/sysinfo.sh`.

## Project Structure
- `scripts/` - System administration scripts
- `docs/` - Project documentation
- `logs/` - Log files

## Version Control
This project uses Git for version control, including branches, commits, merging, and pushing changes to GitHub.
